## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (`AlexKulibaba/swimresults`) via the `gh` CLI. Every issue's title and short description are human-written: ask for them and use them verbatim, never draft or edit them. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
